常见问题

安装时 Windows SmartScreen 拦截

测试版安装包暂无代码签名，属正常现象。点击"更多信息" → "仍要运行"即可继续安装。安装前可核对官网公布的 SHA256。

提示无法连接对方（ECONNREFUSED / 超时）

  • 确认对方已运行软件，且双方在同一局域网；
  • 首次运行请在 Windows 防火墙弹窗中勾选"专用网络"并允许访问；
  • 确认输入的 IP 是对方电脑"本机"卡片里显示的局域网 IP（如 192.168.1.20），不是路由器地址；
  • 如对方修改过端口，IP 后加 :端口（如 192.168.1.20:48218）。

配对时双方校验码不一致

说明可能存在中间人或一方输错了地址：请取消配对，核对 IP 后重新发起，并确保比对的是双方屏幕上同时显示的 6 位码。

通话没有声音

  • 点软件内"音视频设备"卡片的"测试扬声器"：能听到声音说明扬声器正常，查麦克风；
  • 看"使用中"的麦克风是否为期望的设备；
  • Windows 设置 → 系统 → 声音 → 输入，确认输入音量条说话时有反应；
  • 右键任务栏音量图标 → 音量合成器，确认 LAN Call 未被静音。

一台电脑双开测试，第二个实例提示设备被占用

Windows 下摄像头同一时间只能被一个程序使用，属系统限制。v0.2.2 起，接听方摄像头被占用时会自动降级为纯音频通话，不影响验证信令与语音通路。

反馈时请提供

  1. 软件版本号（"本机"卡片或官网下载页可查）；
  2. Windows 版本（如 Windows 11 23H2）；
  3. 问题现象与复现步骤，配对/通话/设备相关的请附上提示文字截图。
